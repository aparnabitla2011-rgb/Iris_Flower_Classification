# Iris Flower Classification

A beginner-friendly machine learning project that classifies Iris flowers into
three species — **Setosa**, **Versicolor**, and **Virginica** — based on their
sepal and petal measurements. Built as part of a Data Science internship
project (Naviotech Solutions).

## Dataset

The classic Iris dataset (150 samples, 4 features, 3 classes), loaded from the
raw CSV file at `data/iris.csv`.

| Feature | Description |
|---|---|
| sepal_length | Sepal length in cm |
| sepal_width | Sepal width in cm |
| petal_length | Petal length in cm |
| petal_width | Petal width in cm |
| species | Target class: setosa / versicolor / virginica |

## How to Run

### 1. Set up environment
```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn streamlit
```

### 2. Run the EDA & hypothesis testing script
```bash
cd notebooks
python 1_eda_hypothesis_testing.py
```
This generates plots in `plots/` and saves the cleaned dataset to
`data/iris_cleaned.csv`.

### 3. Run the model building & evaluation script
```bash
python 2_model_building_evaluation.py
```
This trains Logistic Regression, KNN, and Decision Tree models, prints
accuracy/confusion matrices, and saves the best model to `models/`.

### 4. Run the Streamlit web app
```bash
cd ..
streamlit run app/streamlit_app.py
```
Open the local URL shown in the terminal (usually `http://localhost:8501`).

## Results Summary

| Model | Accuracy |
|---|---|
| Decision Tree | 93.3% |
| Logistic Regression | 91.1% |
| K-Nearest Neighbors | 91.1% |

Hypothesis testing confirmed that sepal length differs significantly between
Setosa and Versicolor (t-test, p < 0.001), and petal width differs
significantly across all three species (ANOVA, p < 0.001).
